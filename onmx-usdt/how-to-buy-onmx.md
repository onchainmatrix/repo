# How to Buy ONMX

## Current Route: Seed Access

Before the Public Sale / TGE stage, ONMX is available only through the applicable **permissioned Seed Access process**.

Start only from the official Onchain Matrix website:

**onchainmatrix.com**

{% hint style="warning" %}
Do not use token-sale links, wallet addresses, payment instructions, or contract addresses received only through direct messages, social-media replies, unofficial groups, or third-party websites.
{% endhint %}

## Purchase flow

{% stepper %}
{% step %}
### Open Seed Access

Go to **onchainmatrix.com** and open the official Seed Access interface.

Confirm that:

* the domain is correct,
* the connection is secure,
* the page was reached through an official Onchain Matrix channel.
{% endstep %}

{% step %}
### Confirm eligibility

Seed participation is permissioned.

Complete the eligibility and participation steps presented by the live interface. Participation can be restricted by jurisdiction, participant eligibility, applicable Terms, wallet status, and technical availability.

{% hint style="warning" %}
Do not attempt to bypass eligibility or geographic controls.
{% endhint %}
{% endstep %}

{% step %}
### Connect your wallet

Connect the wallet that will be associated with your Seed transaction and ONMX allocation.

Before approving the connection, verify:

* the connected network,
* the wallet address,
* the requested action,
* the contract or spender address where displayed.

{% hint style="warning" %}
Onchain Matrix and Magna will never need your private key or wallet recovery phrase.
{% endhint %}
{% endstep %}

{% step %}
### Review the transaction terms

Before signing, confirm the current:

* Seed price,
* ONMX allocation,
* settlement amount,
* settlement asset,
* supported network,
* vesting terms,
* applicable Terms,
* receiving or sale contract details.

{% hint style="warning" %}
If the live transaction terms differ materially from the current official documentation, do not proceed until the discrepancy is resolved through an official Onchain Matrix channel.
{% endhint %}
{% endstep %}

{% step %}
### Prepare USDT

Use only the supported USDT token and network displayed by the live Seed interface.

Different networks can use different USDT contract addresses.

{% hint style="warning" %}
Do not send USDT directly to a wallet address unless that payment route is explicitly provided by the official Seed interface and applicable Terms.
{% endhint %}
{% endstep %}

{% step %}
### Approve the required transaction

If a token approval is required, your wallet can display a separate approval transaction before the Seed transaction.

Review:

* spender address,
* token,
* network,
* approval amount.

Avoid unnecessary approvals beyond what the transaction requires where your wallet allows you to set the amount.
{% endstep %}

{% step %}
### Confirm the Seed transaction

Review the final wallet request carefully.

Confirm:

* network,
* contract or destination,
* USDT amount,
* ONMX allocation shown by the interface,
* gas,
* transaction type.

Sign only after the details match the official Seed interface.
{% endstep %}

{% step %}
### Save your transaction record

Keep:

* transaction hash,
* participating wallet address,
* date,
* USDT settlement amount,
* ONMX allocation shown by the interface.

Your transaction hash provides an independently verifiable record of the onchain transaction.
{% endstep %}
{% endstepper %}

## What happens after purchase?

A completed Seed purchase does **not** make the full ONMX allocation immediately transferable.

The Seed allocation follows:

**6-month cliff → 18-month linear vesting → monthly claim availability**

The applicable Seed allocation will be associated with the production vesting infrastructure through **Magna, powered by Kraken**.

Once the allocation has been added to Magna and stakeholder access is active, the participant can use the Magna dashboard to monitor the allocation, vesting timeline, unlocked balance, claimable balance, and completed claims.

See:

**Seed Access → Magna Dashboard — Vesting & Claims**

## At TGE

Seed ONMX is not designed to become unrestricted immediately at TGE.

The live vesting contract and Magna allocation state determine the actual claimable amount at any point in time.

## Public purchases after launch

Official Public Sale, TGE, and DEX purchase instructions will be added only when the relevant production contracts, liquidity, and interfaces are active.

{% hint style="warning" %}

{% endhint %}

Before any future public-market purchase, verify the ONMX token and relevant liquidity contracts through:

**Resources → Deployments & Contract Addresses**

## Security checklist

Before every ONMX purchase-related transaction:

* Start from **onchainmatrix.com**.
* Verify the current Terms.
* Confirm the connected network.
* Confirm the official contract or destination.
* Confirm the correct USDT token where applicable.
* Review every wallet approval.
* Never share a seed phrase or private key.
* Ignore unsolicited payment instructions.
* Save your transaction hash.
